# libGameCore.so static analysis evidence

This directory is generated by `tools/analyze_gamecore.mjs`.

## Files

- `gamecore_analysis.json`: ELF identity, program headers, sections, dynamic tags, symbol counts, string counts, keyword counts, and high-level findings.
- `dynamic_symbols.txt`: all 559 dynamic symbols in `.dynsym` order, using `D` for defined and `U` for undefined entries.
- `undefined_imports.txt`: 239 undefined dynamic symbol names.
- `strings_filtered.txt`: generated locally with all 50,954 printable ASCII runs of at least five bytes and hexadecimal file offsets. It is excluded from Git to keep the repository compact; regenerate it with the command below.
- `keyword_hits.json`: string hits grouped by network, protocol, crypto, account, battle, and shop keywords.

The source APK and native libraries are intentionally not committed. Regenerate the evidence from the recorded APK:

```powershell
node .\tools\analyze_gamecore.mjs `
  .\workspace\analysis\extracted\lib\arm64-v8a\libGameCore.so `
  .\workspace\analysis\gamecore
```
